# AIリスクコンサルティングPJ - リスク提案ナビ 構想・設計ドキュメント

**リスク提案ナビ（RPN）**: 営業の「現場の声」と商品部の「商品・座組の知識」をAIの上で毎日すれ違わせ、新しい提案（型）を生み出し、成功パターンを全員に横展開する二方向ナレッジエンジン。Excel/VBA×社内AIリボンで動く。

**現況（2026-09-01・W5完了時点。以下の段落は当時の記録＝履歴であり、ボタン名は W5.2 で[① 調べる指示文を出す]〜[⑤ ヒアリングシートを出す]の5本へ改められている）**: 設計 v2.5 系が確定し、**実装は W0～W5（実装5波＋修正4波＋社内環境対応・UI/UX改善＝裁定書9～14）まで完了**している。`src/` にVBA 67モジュール（core 8 / app 30 / ui 12 / test 17）、`build/` にブック生成一式、`tools/` に検問スクリプト、`wintest/` に実機テスト環境がある。純ロジックテストは **612本**（`wintest/tests_expected.txt` が正）、実Excel層(b)は **47本**（`modTestsExcel` + `modTestsExcel2`。自己照合つき）。検問は **`python3 tools/gate.py`（全16ゲート一括）** で回すのが標準であり、個別ツールの直接実行はデバッグ時のみ（17章§5-1）。W5では、会社PCがターミナル・PowerShell・Pythonを一切使えないという実機事実に合わせ、HOMEを[① 案件を作る][② 一括実行][③ レポートを出す][④ ヒアリングシート]の番号つき動線へ改修し、ブック内でテストを実行できる「操作ガイド」タブと初回ガイドツアーを追加、[docs/24](docs/24_実機テスト手順書_Windows.md)を黒い画面を使わない手順へ全面書き直した。**未完了は実機テスト（T-41/T-46④⑤）のみ**であり、これが揃うまで配布はしない。経緯の要約は [docs/22 の「実装後記（W0～W4.4）」](docs/22_実装前監査記録_20260829.md)。

## 実装上の最重要事実

- LLMは社内AIリボン「リボンちゃん」経由が主経路（APIキー配布不要・全社PCで動作・管理側ログあり）。確定APIは PoC リポジトリ [kojima1459/notebook](https://github.com/kojima1459/notebook/tree/claude/internal-notebook-lm-chatbot-B6BE7) の `docs/dev/RIBBON_API_CONFIRMED.md`
- 基盤コード（ゲートウェイ・config・ログ・JSON・テスト・ビルド）は同PoCから移植する（12章の対応表）
- 現契約情報の投入は OQ-6 確定まで**匿名化を既定**とする（16章）
- 命名（公開関数・名前付きレンジ）の唯一の正は **14章§6**。新設は司令塔の裁定を経てから14章§6へ登録する（実装が先に名前を作らない）

## 開発時のコマンド

```bash
python3 tools/gate.py            # 全16ゲート一括（標準。成功時1行 / 失敗時のみ詳細）
python3 build/build_rpn.py --dev # 開発版ブック（mock応答）を dist/ へ
python3 build/build_rpn.py --prod
python3 build/build_rpn.py --kb  # ナレッジブック雛形
```

Windows実機での層(b)テストは [wintest/README.md](wintest/README.md) を参照。
