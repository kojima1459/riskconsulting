# AIリスクコンサルティングPJ - リスク提案ナビ（RPN）

> **営業の「現場の声」と、商品部の「専門知識・座組」をAIの上で掛け合わせる。**  
> 現場と商品部の知恵を毎日すれ違わせて新しい提案の「型」を生み出し、成功パターンをチーム全員に横展開する二方向ナレッジエンジンです。  
> ※ WindowsのExcel（VBA）と、社内AIツール「リボンちゃん」で動作します。

---

## 🔒 開発・運用の重要ルール

- **AIの利用経路**  
  社内AIリボン「リボンちゃん」を経由して利用します（APIキーの個別配布が不要で、全社のPCで安全に動作し、管理ログも残ります）。
- **基盤コードの連携**  
  ゲートウェイや設定管理などの基盤コードは、先行PoCリポジトリ [kojima1459/notebook](https://github.com/kojima1459/notebook/tree/claude/internal-notebook-lm-chatbot-B6BE7) の `docs/dev/RIBBON_API_CONFIRMED.md` から移植しています。
- **顧客データの保護**  
  お客様の既存契約データを取り込む際は、安全のため**匿名化（社名や個人情報を伏せる）**を標準運用としています。
- **ルールの厳守**  
  関数の名前やシートの仕様は、必ず [14章§6](docs/spec/14_API設計.md) を正として管理しています。

## 🛠️ 開発者向けコマンド

```bash
# 全ての品質チェックを一括実行
python3 tools/gate.py

# 開発用Excelブック（テスト用のダミー応答モード）を dist/ フォルダへ作成
python3 build/build_rpn.py --dev

# 本番用Excelブックを作成
python3 build/build_rpn.py --prod

# ナレッジブックの雛形を作成
python3 build/build_rpn.py --kb
```

※ Windows実機での詳しいテスト方法は [wintest/README.md](wintest/README.md) をご覧ください。
