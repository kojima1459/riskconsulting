## 結論（v1時点の要約・経緯として保存）

- Gemini案（プロンプト配布＋コピペ運用）は9月キックオフのデモ素材として使い切り、プロダクトとしては採用しない。
- 本命は「リスク提案ナビ」: OpenAI API＋VBAという実在の資産を使った多段パイプライン。社内の実在コンサルメニュー・保険種目・成功事例にグラウンディングし、営業フィードバックでナレッジが増えるほど賢くなる構造。
- 属人化解消の本体はツールではなく「ナレッジ・フライホイール」（エキスパートインタビュー→成功事例ライブラリ→全員の生成へ自動注入）。
