v2.5変更概要（裁定書9: W4.1）: 実物と食い違っていた記載を全て実ラベルへ揃え（業種名「食料品製造業」・種別「新規開拓」・収集レシピの項目名）、本裁定で実装が変わる箇所（受信箱の `judge_to` 判定操作／HOMEの[第2ラウンド開始]／レポートファイル名の日付と連番／入念モードの E-35・E-36 警告がHOMEに出ること／`dossier_tier` の自動昇格／`feedback_done` への遷移／充足度ラベル「高」／業種ドロップダウン）を確認点へ反映し、§12.2の申し送り表を **A-4のみ残** へ全面改訂した。

本書は「操作 → 期待される画面・データ → 確認点（run_log / validate_result / シート状態）」の3点セットで書く。確認点はすべて**シート上に残る事実**であり、実施者の印象ではない。1つでも不一致があればその場で記録し、シナリオを先へ進めない。

## 0. 前提

### 0.1 実行対象

| 項目 | 値 |

### 0.2 開始前チェック（1回だけ）

1. ブックを開き、`はじめにお読みください` シートが**自動的に非表示になり `ナビ` が見えている**こと（12章§2.1 手順①が走った＝マクロが有効である証拠）。
2. `ナビ` の `hm_transport_banner`（赤帯）に「デモ／開発経路で動作中です（本番の判断に使わないでください）（transport=mock）」が出ていること（16章 E-27）。**ここが空なら mock で走っていない**ので中止する。
3. `ナビ` の `hm_kb_status` が「読込OK（メニューN/型N/事例N）」であること。「ナレッジブック.xlsx を本体と同じフォルダに置いて帯の[ナレッジを読み直す]を押してください」なら、`config` の `kb_path` を `dist/ナレッジブック.xlsx` の実パスへ直す（または本体ブックと同じフォルダへ `ナレッジブック.xlsx` を置く＝起動時に自動で見つける。裁定書17 H1）か、帯の[ナレッジを読み直す] を押す。
4. ナレッジブックに mock 応答が参照するID **M-0012 / L-03 / S-0004 / K-0003 / P9 / MC-0107** の行が存在すること（15章§8.1。無いと実在チェックが誤発火して UC1 が落ちる）。
5. `config` の `mock_fault` が空であること。

### 0.3 観測用シートの開き方

`case_data` / `config` / `err_log` / `usage_log` / `run_log` の5枚は非表示（hidden）である。確認のときだけ、Excelのシート見出しを右クリックして「再表示」から開き、確認が終わったら再び非表示へ戻す。

`kb_snapshot` は **veryHidden**（「再表示」の一覧に出ない）であり、通常の操作では開けない。本書はこのシートの中身を確認点にしない。実行時に作られる作業シート（`enum_hidden` / `paste_buf` / `中身`。13章§2.9）も同じく veryHidden なので、一覧には出ない（`中身` だけは[中身を見る]の間だけ可視になる）。**`vba_src` は配布物に存在しない**（v3.4・裁定書27 W9-A で自己インストーラごと廃止。開発用フォールバック `--vba-mode=installer` でだけ作られる）。
