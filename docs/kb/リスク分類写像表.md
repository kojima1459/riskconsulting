# リスク分類写像表(RiskMap分類 → category 10分類)

D-2で `リスクライブラリ.category` を機械的に割り当てるための写像表。`category` は19章§3のリスクユニバース10分類で、S2出力の`category`と同一語彙。

## 固定写像(業種によらず一意に決まるもの)

| RiskMapのリスク分類 | category |
|---|---|
| 火災、爆発 | facility_bcp |
| 落雷・風水雪災 | facility_bcp |
| 地震・噴火・津波 | facility_bcp |
| 労働災害 | hr_labor |
| 雇用問題（ハラスメント） | hr_labor |
| 製造物責任 | manufacturing_quality |
| 従業員の不正・犯罪 | brand_social |

`従業員の不正・犯罪` は `brand_social` (対外的な信用・レピュテーション毀損の色彩が強い事例が多い) をデフォルトとし、着服・横領など専ら財務・コンプライアンス色が強い個別事例は `legal_regulatory` との境界が曖昧になりうる。本バッチでは一律 `brand_social` を採用し、個別の再分類が必要な事例があれば運用時にconcernsとして扱う。

## 業種チャプターで分岐するもの

| RiskMapのリスク分類 | 条件 | category |
|---|---|---|
| 施設の欠陥、管理不適、業務・作業のミス | 業種マスタの industry_code チャプターが 06〜32(建設業・製造業) | manufacturing_quality |
| 施設の欠陥、管理不適、業務・作業のミス | 上記以外(小売・サービス・宿泊・娯楽等) | sales_customer |

判定は `industry_code` の先頭2桁(「-連番」の連番部分は無視)で機械的に行った(`06〜32`を製造業・建設業とみなす)。

## D-3事故事例・D-4判断基準での準用

- 事故事例(`事故事例`シート)の `category` も本表の固定写像を踏襲した。事故の内容が明確に該当しない場合(取引先倒産等)は `finance_counterparty`、情報漏えい・サイバー攻撃は `digital_info`、役員賠償(D&O)・契約紛争は `finance_amount`ではなく実態に応じて `finance_counterparty` または `legal_regulatory` を個別判断した。
- 判断基準(D-4)の `category` 列は存在しない(スキーマに含まれない)ため、本表の対象外。

## concerns(迷った対)

- `従業員の不正・犯罪` のうち、横領・着服など財務統制の失敗が主因の事例は `legal_regulatory` の方が実態に近い可能性がある。今回は写像表どおり機械的に `brand_social` で統一した。
- D&O(役員賠償)・株主代表訴訟の事例は10分類のどれにも明確に一致しないため `finance_counterparty` を割り当てた(資金提供先・取引先絡みの実質判断が多いため)。10分類にD&O固有のカテゴリがない点は司令塔判断を仰ぎたい。
