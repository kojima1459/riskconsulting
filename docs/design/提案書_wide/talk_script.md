## 11
■読み上げ
保険では引き受けにくいものの、経営上重要と考える6つのリスクをまとめました。時間軸の欄は、いつ頃顕在化しそうかという当社の見立てです。
1つ目は、原材料・エネルギー・為替の構造的な変動です。貴社も公表資料で挙げておられる課題で、価格上昇そのものは通常の保険では補償されません。調達の分散や価格スライド条項、為替ヘッジなどを組み合わせ、天候指数保険などで一部を補う形になります。
2つ目は、職人技能と商品文化の継承です。技能の喪失は保険では代替できませんので、技能の見える化や担当の複線化が備えの中心になります。
3つ目は、AIによる偽情報やなりすましです。ブランド監視と危機広報の手順に加え、削除や法務対応の費用が補償できるかを確認します。
4つ目は、プラットフォームへの依存です。アプリからLINEへの会員基盤の移行を踏まえ、顧客情報の移行可能性や、障害時の休業損失がサイバー保険で対象になるかを確認します。
5つ目は気候変動による農産物の供給変動、6つ目は観光・交通需要の急変です。いずれも需要減そのものは保険の対象外になりやすく、周遊商品やイベント収益の分散といった経営施策と、キャンセル保険などを組み合わせて備えます。
