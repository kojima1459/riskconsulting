# 19. 用語集・共通レジストリ・整合性チェックリスト v2.0

本章は10〜17章の全文書に共通するID・enum・名称の**唯一の正**。文書間の矛盾はまず本章に合わせて解消する。実装ではenum変換表（§3）を modUICase の定数として持ち、本章とのdiffゼロをテストする（17章 §4-2）。

## 1. 用語集

| 用語 | 定義 |
|---|---|
| プレイ | 共通シャーシ（構造化→突合→選択肢→成果物→記録）の上で動く機能単位（PL-01〜08） |
| 使うエンジン | 案件単位の提案生成（PL-01/02）。営業・商品部が日常利用 |
| 生むエンジン | 受信箱・案件事実・ウォッチから型を生む月次/四半期の仕組み（PL-03/05/06） |
| 型（scheme） | 実在の座組の缶詰。型ライブラリの1行（S-NNNN） |
| パターン | 座組の文法（P1〜P15・固定15種。docs/07） |
| 機構 | 掛け合わせ用の技術・仕組みの部品（MC-NNNN） |
| 生存文法 | 投稿・提案が通る4条件 a〜d（docs/05 §1） |
| 棄却類型 | ドロップ理由の統制語彙 T0〜T10（docs/05 §1） |
| 3手 | 壁を越える方法: 加入経路(entry_path)/給付形態(benefit_form)/引受主体(underwriter) |
| 受信箱 | 投稿・現場の声・ウォッチ結果の一次受けシート。プリフライト診断の入口 |
| 判断台帳 | UW判断の事実記録。PL-07/08の学習データ |
| ナレッジ編集長 | 月次編集会でAIの下書きを裁く役割（P3ペルソナ） |
| シード | PoC開始時に装填する初期ナレッジ（docs/04・05・07） |
