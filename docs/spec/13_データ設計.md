# 13. データ設計（シート＝テーブル定義）v2.0

原則: 1シート=1テーブル。1行目=物理名ヘッダ（英小文字snake_case）。VBAアクセスは列名ベース（列番号ハードコード禁止・ヘッダ探索は modUtil）。enumの正は19章レジストリ。

## 4. データ保全・ライフサイクル

- `sN_json`（LLM生出力）と `pf_json` は不変（監査・プロンプト改善の一次データ）
- 案件削除はHOMEからのみ（案件一覧＋case_data＋フィードバックの同時削除・確認必須）。受信箱・判断台帳・run_logは削除しない（累積が資産）
- ナレッジブック編集は管理者1名運用。本体からの追記失敗時はローカル退避→次回起動時再送（16章 E-13）
- 個人名の保存禁止（owner/recorded_by はWindowsユーザー名までとし、顧客側個人名は全シートで入力禁止の注記＋E-05チェック）
