## 1. 裁定（何をどう直すか）

### 班A（build・ロック・コピー・窓・テストログ）

**A-1（F-1）入力規則を名前付きレンジ方式へ**
- `build/build_rpn.py::_add_data_key_validation`: インライン list をやめる。最終ブックに **very hidden シート `enum_hidden`**（実行時 `modBootNavi.BN_ENUM_SHEET` と同名）を作り、A1 から `enums.data_key` の値を縦に書き、**定義名 `enum_data_key`**（`BN_NAME_DATA_KEY` と同名）を張り、`DataValidation(type="list", formula1="=enum_data_key", ...)` を `case_data` の data_key 列（2〜51行）へ。
- 自己検証 (h)（2895行付近）: `formula1` を `"` で割る比較をやめ、`=enum_data_key` を解決して値集合を比べる（`wb.defined_names` → シート範囲 → 値）。**検問を弱めない**。
- `_apply_dv`（本体）の `DV_INLINE_LIMIT` 超過は現状「省略して報告」。今回は **255 字超の enum が data_key 以外に無い**（`_note` 279値は DV に使われていない）ので本体側は触らない。ただし **超過が起きたら BuildError で止める**（黙って省略しない）に変える。`dv_skipped` の告知は残してよいが exit を非0に。
- 実行時 `modBootNavi.RestoreDataKeyHiddenRange / ApplyDataKeyValidation` は既存のまま（同じシート名・同じ定義名なので二重にならない）。**既存シートがあれば再利用する**ことを確かめる（`EnsureEnumHiddenSheet` は `Worksheets(名前)` を先に探しているので OK のはず。実測して報告）。
- `tools/sheet_check.py` が最終ブックを見ている場合は `enum_hidden` を「ガードシート」として許容に加える（見ていなければ触らない。**どちらだったかを報告**）。
- 検証: `python3 build/build_rpn.py --final` → `python3 -c` で sheet14 の DV formula1 が `enum_data_key` であること、`bin-rt-final`・`lo-xlsm-final`・`ship` が緑。

**A-2（F-2）[テストを実行] が自分のロックで自分を SKIP させない**
- `modNaviActions.IsLongAction` から `"run_tests"` を外す。代わりに `ActRunTests` に**再入防止の静的フラグ**（`Static running As Boolean`。走行中なら `busy` 応答）を置く。ShowBusy の表示は現状どおり。
- 期待: HTML から [テストを実行] しても `T47B-V1N-06/07` と `貼ったものの保存` 系が SKIP せず走る。**LibreOffice では層(b)は走らない**ので、純テスト・compile で回帰が無いことと、`E0602 busy:HTML:run_tests>` が構造的に出ないこと（`grep` で IsLongAction の一覧に run_tests が無い）を示す。

**A-3（F-3）コピーは Excel 自身が行う（HTML は補助）**
- `ui/app.js::copyPrompt`: 先に `send('copy_prompt', {prompt_no, text})` を送り、VBA が **`modUICase7.ClipCopyText(text)`** でコピーする。VBA 応答に `copied:true/false` を載せ、`false` のときだけ既存の `copyText()`（IE clipboardData → 手動コピーのモーダル）へ落とす。
- `ActCopyPrompt`: `data.text` を受け取り `ClipCopyText` を呼ぶ。`text` が空なら `PromptTextOf(n, ...)` で組み立てる（サーバ側で正を持つ）。`ClipCopyText` が `"` やタブを含む本文を拒否する規約なので、**調査指示文8本に `"` とタブが入っていないこと**を純テストで固定する（入っていたら `「」` へ寄せる。15章の文面を変えるなら 15章も同時に）。
- 成功メッセージを **貼り付け先まで**言う: `調査指示文をコピーしました。社内の調査ページで「レポート調査」→「指示文」欄に貼り付け、「調査の広がり」は「集中（1観点）」を選んでください。`（docs/08 §1y の既定。文言は 11章にも同じ字で載せる）。
- 開く URL は `dr_url_full`（`…/research/instructions`）のまま。実機で「メニュー」へ飛んだのは先方のリダイレクトの可能性があるので、**URL を変えない**。ただし応答 JSON に `opened_url` を載せ、状態行に URL を出す（既存の `dr_open_after_copy` の案内文と同じ場所）。

**A-4（F-5）[隠す] と再表示・サイズの4段目**
- HTML ヘッダに **[隠す]**（`data-action="hide"`）を [画面サイズ] の隣へ。VBA: `modNaviHost.HideNaviTool`（`gForm.Hide`。破棄しない）。
- 再表示: Excel 側に **ただ1枚だけ見えるシート `ご案内`**（無ければ新設・build にも登記・sheet_check に許容）を用意し、大きく「この Excel は触りません。HTML 画面を閉じた／隠したときは下のボタン」＋図形ボタン **[ナビ画面を開く]** → `modNaviHost.OpenNaviTool`（Hide 済みなら `Show 0` で復帰）。HTML モードでは他の全シートを veryHidden のまま（既存の `LaunchIfHtml` 系の処理を確認して、`ご案内` だけ可視にする）。
- `CycleSize` に 4段目「小（半分）」を足す（幅 `Application.Width*0.5`・高さ `*0.6`、最小 640×400 は維持）。
- 実機依存で LibreOffice では見えない部分なので、**純テストで `IsLongAction`・action 名の一致（`tools/action_check.py` の JS⇔Dispatch）**を通し、11章の画面図に [隠す] を追記。

**A-5（F-8）自己テストの記録は別ファイルへ**
- `modLog` に `SetSelfTestMode(ByVal on As Boolean)` を追加（CONTRACT 登記）。ON の間、`LogError/LogUsage` の書き先ファイル名を `err_log.csv → err_log_selftest.csv`、`usage_log.csv → usage_log_selftest.csv` に切り替える（同じフォルダ・同じ列）。
- `modTestsRunnerUi.RunAllTestsHeadless`（と シート側の実行口）の冒頭で ON、終了時（正常・異常とも）に OFF。
- 純テスト: ON/OFF でファイル名が切り替わること、OFF に戻ること（例外経路も）。
- docs/24 §4.2 に「自己テストの記録は `err_log_selftest.csv` に入る。`err_log.csv` には残らない」。

### 班B（PII 方針・文言・docs）

**B-1（F-4）貼付の PII は「見せて続行」が既定（ブロックは設定で）**
- config `pii_paste_policy`（値 `warn` 既定／`block`）を `modBoot.RegisterDefault` に追加（13章§2.3・19章・`tools/config_check.py` の5点一致に登記）。
- `ActPasteMaterial`: `warn` のときは **登録を止めない**。応答は `kind:"warn"` で、メッセージに **何を検知したか**を出す: 種別を日本語に（person=人名らしき語／email=メールアドレス／phone=電話番号／policy_no=契約番号らしき数字列）、件数、**先頭3件の断片**（各 12 字まで・末尾は `…`）。例: `個人情報らしき記述を検知しました（人名らしき語 2件: 山田太郎様、佐藤様／電話番号 1件: 053-4xx-…）。公開情報ならそのままで構いません。個人の連絡先なら伏せ字にしてから登録し直してください。登録は完了しています。` `block` のときは従来どおり（この文言にも断片を出す）。
- `modPii` に **断片を返す口**（`Public Function SnippetsOf(sText, maxItems, maxLen) As String`。`;` 区切り）を追加（CONTRACT 登記）。`ScanSpans` は Private のまま。
- **AI へ渡す前の匿名化は別の層**（`anonymize_default` / `MaskText`）で従来どおり行う。ここで通した本文が生のまま AI へ行くわけではないことを 16章 E-05 に1行で明記。
- シート予備側 `modUICase7` の同じ分岐にも同じ方針を適用（片方だけ直さない。裁定書42 の教訓）。
- 純テスト: `warn` で登録される／`block` で止まる／メッセージに断片と件数が入る／policy_no 単独の既存挙動が変わらない／`SnippetsOf` の切り詰め。
